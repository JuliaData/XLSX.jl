Supported features

This page lists the Excel features XLSX.jl works with, the functions for each, and where each is documented. The second table lists features XLSX.jl doesn't create or edit, so you needn't search for them.

Functions that add, change or remove something need a file opened with mode="rw", or one started with XLSX.newxlsx. Functions that only read work on any file.

What XLSX.jl doesn't do

FeatureNotes
Calculating formulasXLSX.setFormula writes the formula, and Excel recalculates it when the file is opened. Its value reads as missing until then, unless you give the value yourself: see Cached values.
Filtering by colour or by iconXLSX.setAutoFilter filters by values, conditions, top or bottom items, the average and dates.
Creating region map charts, and some chart subtypesSee the charts Limitations.
Pivot tables, slicers and timelinesNo functions to create or edit them. A file holding them keeps them when it is edited and saved, but they aren't updated: refresh a pivot table in Excel.
Shapes filled with pictures, connectors, grouped shapes and SmartArtXLSX.addShape adds single preset shapes with text, fill and border.
Pictures in headers and footersXLSX.setHeaderFooter sets their text, fields and fonts only.
Password-encrypted filesTo read an encrypted file, decrypt it first with XLSXDecrypt.jl.
VBA macrosNot created or edited.

Opening a file that holds any of these in mode="rw" and saving it over the original deserves care: see the warning on XLSX.openxlsx.
