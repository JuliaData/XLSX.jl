Zoom, gridlines and the view

XLSX.setSheetView sets how a worksheet looks when Excel opens it, as Excel's View tab does: the zoom, whether gridlines, headings and zeros are shown, the direction of the sheet, where it is scrolled to, and which cells are selected. These change the workbook, so open the file with mode="rw" (or start from XLSX.newxlsx). XLSX.getSheetView reads them from any file.

julia> s = XLSX.newxlsx()[1];

julia> XLSX.setSheetView(s; zoom=150, showGridLines=false)

julia> v = XLSX.getSheetView(s);

julia> (v.zoom, v.showGridLines)
(150, false)

Only the settings given are changed. They are:

KeywordExcelDefault
zoomView → Zoom, 10 to 400 percent100
viewView → Normal / Page Layout / Page Break Preview: :normal, :pageLayout, :pageBreakPreview:normal
showGridLinesView → Gridlinestrue
showRowColHeadersView → Headings, the 1, 2, 3 and A, B, Ctrue
showZerosFile → Options → Advanced → Show a zero in cells that have zero valuetrue
rightToLeftPage Layout → Sheet Right-to-Leftfalse
topLeftCellthe cell scrolled to the top left of the windowA1
selection, activeCellthe selected cells, and the one with the cursorA1

Excel keeps a zoom for each view, so setting zoom changes the zoom of the sheet's current view, and switching view brings back the zoom that view had.

To open a sheet at a particular place, scroll to it and select the cells:

julia> XLSX.setSheetView(s; topLeftCell="A20", selection="B22:D30", activeCell="C25")

julia> v = XLSX.getSheetView(s);

julia> (v.topLeftCell, v.activeCell, v.selection)
(A20, C25, "B22:D30")

A selection can be several ranges separated by commas ("B2:D5,F7") or a defined name. A selection given alone has its first cell active, and an activeCell given alone is selected on its own.

With frozen panes

With frozen or split panes (Freeze and split panes), topLeftCell is the top-left cell of the part that scrolls, and the selection is the active pane's, as Excel keeps them:

XLSX.freezePanes(sheet, "B3")                                # freeze rows 1-2 and column A
XLSX.setSheetView(sheet; topLeftCell="B40", activeCell="D45")  # scrolled down to row 40

With frozen panes, topLeftCell must be below and to the right of the frozen rows and columns. Freezing counts from row 1 and column A, so XLSX.freezePanes scrolls the view back to the top first.
