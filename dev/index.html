XLSX.jl

Introduction

XLSX.jl is a Julia package to read and write Excel spreadsheet files.

Internally, an Excel XLSX file is just a Zip file with a set of XML files inside. The formats for these XML files are described in the Standard ECMA-376.

This package follows ECMA-376 to parse and generate XLSX files.

Features

  • Read and write cell values, ranges and whole tables through the Tables.jl interface, so data goes straight to and from a DataFrame (see the XLSX Tutorial)
  • Stream the rows of large files with eachrow and eachtablerow, without loading the whole sheet
  • Cell formatting and conditional formats
  • Formulas and defined names
  • Insert and delete rows and columns, with formulas and everything else that refers to them updated
  • Data validation, including drop-down lists
  • AutoFilter buttons on plain ranges
  • Sheet visibility, tab colours, protection and page setup
  • Native Excel Tables
  • Merged cells, column widths and row heights, hidden and grouped rows and columns and freeze/split panes
  • Hyperlinks, images and cell comments
  • Native Excel charts: read, format and create (experimental)
  • FileIO.jl integration (see the FileIO Tutorial)

Quick Start

using XLSX, DataFrames

df = DataFrame(name = ["a", "b", "c"], value = [1.5, 2.5, 3.5])
XLSX.writetable("data.xlsx", df; sheetname = "Data", overwrite = true)

df2 = DataFrame(XLSX.readtable("data.xlsx", "Data"))

XLSX.openxlsx("data.xlsx", mode = "rw") do xf
    sheet = xf["Data"]
    sheet["C1"] = "Total"
    XLSX.setFormula(sheet, "C2", "=SUM(B2:B4)")
    XLSX.setFont(sheet, "C1"; bold = true)
end

Requirements

  • Julia v1.10 (LTS) or more recent

  • Linux, macOS or Windows.

Installation

From a Julia session, run:

julia> using Pkg

julia> Pkg.add("XLSX")
