Protecting a sheet

Protecting a sheet changes the workbook, so open the file with mode="rw" (or start from XLSX.newxlsx). The settings can be read from any file.

XLSX.protectSheet protects a worksheet, as Excel's Review → Protect Sheet does, so that its cells can't be changed in Excel:

XLSX.protectSheet(sheet)
XLSX.protectSheet(sheet; password="secret", sort=true, autoFilter=true)

Keywords say what users may still do, as the check boxes in Excel's dialog do: selecting cells is allowed by default, and everything else (formatting, inserting and deleting rows and columns, sorting, filtering, ...) is not. See XLSX.protectSheet for the full list.

Warning

Sheet protection guards against mistakes, not against anyone determined to change the sheet. The password is stored as Excel's legacy 16-bit hash, which is easily broken, and other programs, XLSX.jl among them, read and write a protected sheet as any other.

julia> XLSX.isSheetProtected(sheet)
true

julia> XLSX.getSheetProtection(sheet).sort
true

julia> XLSX.unprotectSheet(sheet)
true

Unlocking cells

Every cell is locked by default, so protection locks the whole sheet. To let users fill in some cells of a protected sheet, unlock them with XLSX.setCellProtection, as the Protection tab of Excel's Format Cells dialog does:

XLSX.setCellProtection(sheet, "B2:B20"; locked=false)   # the cells to fill in
XLSX.setCellProtection(sheet, "D2:D20"; hidden=true)    # hide these cells' formulas
XLSX.protectSheet(sheet)

Empty cells can be unlocked too: they are given the format without a value. A hidden cell still shows its value; only its formula is kept from the formula bar. Neither setting has any effect until the sheet is protected.

Whole columns ("B:B") and rows ("5:6"), and : with row or column numbers (setCellProtection(sheet, :, 2; locked=false)), reach only as far as the sheet's used range, as with the other format functions. Rows added below it later are locked, so to leave room for new entries give an explicit range, such as "B2:B500".

julia> XLSX.getCellProtection(sheet, "B5")
(locked = false, hidden = false)

Protecting the workbook

XLSX.protectWorkbook protects a workbook's structure, as Excel's Review → Protect Workbook does: in Excel, its sheets can't then be added, deleted, moved, renamed, hidden or unhidden. It is separate from protecting each sheet, which guards the cells.

julia> xf = XLSX.newxlsx();

julia> XLSX.protectWorkbook(xf; password="secret")

julia> XLSX.getWorkbookProtection(xf)
(password = true, structure = true, windows = false)

julia> XLSX.unprotectWorkbook(xf)
true

The password is stored as Excel's legacy hash, as a sheet's is, so it keeps out mistakes rather than anyone determined. windows=true also locks the workbook's windows, an option only Excel for Mac and older versions of Excel use. XLSX.jl itself can still change the sheets of a protected workbook.
