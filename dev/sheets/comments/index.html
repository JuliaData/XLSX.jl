Comments

Adding or deleting comments changes the workbook, so open the file with mode="rw" (or start from XLSX.newxlsx) and save it afterwards. The functions that only read work on any file.

A comment, called a Note in recent Excel versions, is text attached to one cell. The cell shows a small red triangle, and the comment appears when the mouse is over it. XLSX.addComment adds one, or replaces the cell's existing comment:

XLSX.addComment(sheet, "B3", "Checked against the 2024 accounts"; author="Finance")
XLSX.addComment(sheet, 5, 2, "Line one\nLine two"; visible=true)   # always shown

width and height set the size of the pop-up box in pixels.

To read comments back, use XLSX.getComment for one cell or XLSX.getComments for a sheet or workbook. Each comment is a NamedTuple of (sheet, ref, author, text), and a cell with no comment gives nothing:

julia> XLSX.getComment(sheet, "B3")
(sheet = "Summary", ref = "B3", author = "Finance", text = "Checked against the 2024 accounts")

julia> XLSX.getComment(sheet, "C3") === nothing
true

Notes that Excel writes usually begin with the author's name ("Name:\n…"), because Excel puts it in the note text itself. getComment returns the text as stored.

XLSX.deleteComment removes a comment. It returns true if there was one to remove:

XLSX.deleteComment(sheet, "B3")   # true

Threaded comments

Excel 365 also has threaded comments, which hold a conversation: a comment and its replies, each with its author and date, and the thread can be marked resolved. XLSX.addThreadedComment starts a thread on a cell and XLSX.addThreadedReply adds to it. XLSX.setThreadedCommentResolved marks a thread resolved, or reopens it with false:

XLSX.addThreadedComment(sheet, "B3", "Is this right?"; author="Ana")
XLSX.addThreadedReply(sheet, "B3", "Yes, checked."; author="Ben")
XLSX.setThreadedCommentResolved(sheet, "B3")

Each author becomes one of the workbook's people, which Excel shows by name. The date of each comment is the time it was added, in UTC, unless date gives another. XLSX.getThreadedComments and XLSX.getThreadedComment read the threads back:

julia> t = XLSX.getThreadedComment(sheet, "B3");

julia> t.author, t.text, t.resolved
("Ana", "Is this right?", true)

julia> [(r.author, r.text) for r in t.replies]
1-element Vector{Tuple{String, String}}:
 ("Ben", "Yes, checked.")

XLSX.deleteThreadedComment removes a thread with all its replies.

A cell has either a note or a thread, not both. For a cell with a thread, Excel also stores a note holding the conversation as text, for versions of Excel without threads. XLSX.jl writes that note too, and keeps it up to date as replies are added. getComment returns it, but addComment and deleteComment refuse a cell with a thread, so that the two can't get out of step.
